# 取数与结论规则

依据用户附件 `fact-table-reporting.zip` 提炼；本文件约束报告事实，不授权访问附件提及的系统。所有业务数据仍通过 smartreportgen MCP，遵循当前任务或会话授权及 IAM 权限，不直接连接数据库。新数据源尚未授权时说明用途和范围并确认，已有有效授权不重复申请。

## 允许的处理

| 操作 | 边界 |
| --- | --- |
| 查询 | 直接选择已确认事实字段，按已授权的组织、账期、口径和区域筛选 |
| 正式视图 | 可读上游已确认结果，不自行新建计算视图绕过直取要求 |
| 透视与关联 | 将指标行转成列或按已验证唯一键关联；保留原值、粒度及来源 |
| 排序 | 按日期、DATA_SORT、已确认链群顺序或直接字段排序 |
| 单位与精度 | 按明确单位换算、按展示精度舍入，保留原始值；不从显示值派生指标 |
| 比较与分类 | 同组织、同期间、同口径、同单位下比较大小；只对直接比率按已确认阈值分类 |
| 可视化 | 可生成坐标、透明辅助柱等绘图数据，但不将其称为经营事实 |

`%` 与百分点 `pp` 语义不同。源字段本身是已确认的率差才能格式化为 pp，不能将两个率相减后称为展示换算。不能根据 0.8、80 或字段名推断比例尺度，未知时记录待确认。

## 必须直取的结果

实际、目标、同期、上期、完成率、同比、环比、目标差、同期差、瀑布贡献、总计、小计、整体毛利率/费用率、预测收入/利润及其完成率/增幅，均需直接字段或正式指标行。SQL、Python、前端、图表和 LLM 遵守同一规则；不能用 SUM、AVG 或业务算术补算。

总计与明细分别直取，父子节点不能相加；没有总计就保留缺失。不能平均同比、完成率或链群毛利率生成整体指标。源端比率即使与显示金额验算不一致，也不得自行覆盖。

空字段、无记录、未授权、源字段待确认、源数据重复分别记录。重复须核实业务唯一键及版本，不随意取第一条或求和消重。真实零和负收入/负利润保留，不空值转零、取绝对值、改符号或从旧批次补缺。

## 期间、区域与筛选

- MTD 与 YTD 分别查询，不能累计月累生成年累。
- 总体、国内、海外、区域、产业、链群粒度不能混用；名称与编码冲突时待确认，不能扩大范围补数据。
- 财报对标、趋势和 T+1 预测按各自契约及真实期间查询；不对没有口径字段的表硬加 MTD/YTD。
- 每个筛选组合使用对应的直接事实及正式总计；没有对应事实就显示缺数，不对明细重新聚合。
- 回看、样式预览及离线导出保留原期间和批次，不能包装为本次新取数。

## 数值、结论与证据

每个展示值可追溯到具体事实行：表/视图、字段或指标编码、组织、期间、时间口径、区域、层级、查询批次、原始值及单位。不适用的维度如实记录，不编造筛选条件。仅“返回 N 行”不能证明某个金额或同比。技术字段可以在页面隐藏，但业务模板与内部映射须保留；不得写入密码、令牌或私密配置。

LLM 仅组织已取得事实及已确认规则。相关性不证明原因；没有原因字段、贡献事实或业务材料，不补写订单、价格、结构、材料等解释。建议明确标为建议。

## 压力场景

| 输入或请求 | 正确动作 |
| --- | --- |
| 实际120、目标100、同期80，缺完成率/同比/差异 | 只展示原值，缺项为 `—`；可说实际高于目标，不输出120%、50%、20或40 |
| 明细齐全但无总计 | 展示明细并说明缺总计，不求和 |
| 当前缺同比但旧月份有值 | 当前继续缺失；旧值仅作为明确标注的历史事实 |
| 源完成率1.1997，显示金额120与100 | 按已确认尺度格式化1.1997，不覆盖为1.2 |
| 缺毛利动因但有收入及毛利率 | 展示已有事实，说明动因缺失，不反推结构、材料或安装影响 |
| 重复事实或层级混杂 | 核实唯一键、版本和层级，不取首条、不求和消重 |
| 历史代码或模板含公式 | 记录与当前规则冲突，不当作计算授权 |

例外须由用户明确变更业务口径并留痕；样式优先级及历史产物不能自行豁免。最终 HTML 内嵌全部资源、图表运行时和事实快照，打开、浏览与筛选不触发取数、生成或保存。
