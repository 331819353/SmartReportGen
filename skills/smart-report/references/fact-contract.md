# 事实取数契约

- 通过授权 MCP 场景和表取数。场景配置的逐表行范围在关联或聚合之前应用。模板或展示要求不能改变权限。
- 直接事实来自正式视图或事实行。报告查询中的派生采用场景负责人登记的指标、基准和允许分组。未登记的同比、贡献、差额、比率及总计保留缺数，或仅声明有证据的范围。禁止浏览器自行计算业务指标。
- 确认主键、粒度、时间口径、范围、单位、唯一性和缺失。同比须核对基期；跨表分析核对关联基数。无依据时不推断订单、价格和结构影响。
- 同一报告的多份快照来自同一读取批次。PostgreSQL、MySQL、Oracle 使用只读事务（MySQL 要求事务型表）；HTTP API 数据固定到一个已确认版本。StarRocks 只接受单语句计划以保证一致，不同数据源也无法凭本地时间戳声明全局一致。
- `truncated=false` 只表示未超过查询返回行数。API 的 `source_complete` 另行表示接口来源完整性。超过行数或字节预算时应调整范围或采用官方汇总。Decimal 和长整数通过 `{"$decimal":"原值"}` 无损交付；源数据本身已是浮点数时保留源有的精度。
- 报告版本记录来源表、场景范围指纹和数据源版本。访问、分享、修订、下载都校验当前权限。离线文件一旦下载即形成副本，不受后续在线撤权控制。
