# 展示契约与服务端验收

| 规则 | 正式交付约束 |
| --- | --- |
| R-01 | 声明生效规则来源。展示优先级为用户明确要求、场景、通用、内置默认。事实和权限校验独立执行。 |
| R-02 | 可引用查询中的直接事实，或使用场景负责人登记且允许当前分组的官方聚合与派生。 |
| R-03 | 绑定必须匹配已核实的字段与粒度。空值及非唯一事实显示「—」，清除上一次的判定。 |
| R-04 | 筛选、正文、指标和图表由同一运行时刷新，缺失的总计或分组不得由前端补算。 |
| R-05 | 定量正文使用 `{{metric}}`，静态解释有适用范围及业务依据。 |
| R-06 | 交付为内联样式、脚本和所需快照字段的单文件，浏览及筛选不请求网络。 |
| R-07 | 比率明确声明源尺度。 `rate_symbols=percent-only` 时率差亦统一显示百分号。 |
| R-08 | `SrgDisplay` 负责格式、符号及单位。图表布局百分比是绘图属性。 |
| R-09 | 状态基于未经展示舍入的原值。支持正向、反向及预警阈值，所有状态色使用统一映射。 |
| R-10 | 服务端审计源与展开内容，以真实 Chromium 验证数字、状态、代表性筛选、重置、宽窄屏及离线请求。只提交绑定当前验收哈希的预览。 |

`preview_report_spec` 完成 R-01 至 R-10 的自动检查并返回 `verification`。编译器在正文、指标卡、表格、图表、格式化、缺失态上复用同一个字段绑定与运行时。自然语言分析是否选对口径仍需用真实业务资料核实。审核记录不能替代该业务判断。

`audit_report.py` 的 CLI 可诊断历史自编 HTML 或独立示例。它填写的本地 Review JSON 仅是诊断记录，无法作为保存证据。历史草稿由 `preview_report_html` 返回静态检查项。通过 `get_preview_file` 从认证后的 MCP 分页取得正式预览；生产环境的浏览器下载链接仍使用 IAM。
