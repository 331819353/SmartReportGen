# 展示与离线校验

## Chromium 验收

- 展开后的报告是完整 HTML 单文件，包含所用样式、脚本、数据和图表库。加载、操作控件和调整视口期间的外部请求或脚本异常会阻断保存。
- 页面正文及草稿章节须呈现内容。ECharts 实例须渲染有尺寸的 Canvas 或 SVG。服务端试用若干可见的筛选控件、标签页或重置按钮。
- 窄屏横向溢出或空表返回 `warnings`。失败时可查看章节、控件、异常或外部地址诊断。

## 展示复核

- 标题、账期、地区、筛选、指标和结论使用一致口径。对比项注明基准，筛选时同步更新数值、结论和状态。区分空值与零，缺失用「—」或可见说明。
- 使用确认的单位和比例尺度，区分占比、变化率与绝对率差。用全精度值判定状态，只给有业务含义的数值着色，持平、缺失和参考值使用中性样式。
- 遵循当前用户、业务场景、通用规则、内置主题的展示优先级。统一同类卡片与图表，复用一致的分类色、坐标轴和图例。数值列右对齐，宽表使用内部滚动容器，窄屏检查标签和筛选器可读性。
- 用正式事实支持结论。Chromium 验证报告可运行，指标口径、来源和推论需在交付前对照授权数据核实。
